**Web Development | Machine Learning | Security**

An improved CAPTCHA verification system designed to distinguish genuine human users from automated bots using CAPTCHA validation and behavioural analysis.

**Key Features**
- Dynamic CAPTCHA generation.
- Randomized CAPTCHA characters and expiration.

- Multiple-attempt detection.

- Machine learning prototype.

**Tech Stack:** HTML, CSS, JavaScript, Node.js, Express.js, Python, Pandas, Scikit-learn, Random Forest.
